# Сайт «PlusheviiKruk»

Одностраничный сайт для онлайн-заказа вязаных игрушек ручной работы PlusheviiKruk. Стиль: мягкая пряжа и тёплый дом — сливочный фон, пастельные цвета, вязаная фактура и «строчки»-стежки. Заказ принимается в мессенджере [заполнить: Telegram / Instagram / ВКонтакте].

**Основное сообщение:** тёплые игрушки, связанные руками: мягкие друзья для детей и взрослых.

Сайт собирается в Claude Code по правилам из `CLAUDE.md`. Данные магазина (каталог, цены, материалы, акции, условия, контакты) берутся только из этого файла. Поля с пометкой [заполнить] нужно дописать до публикации, а перед каждой публикацией — проверить, что данные актуальны.

## Где опубликован

Сайт: https://plusheviikruk.github.io/ — репозиторий `plusheviikruk/plusheviikruk.github.io` (организация plusheviikruk на GitHub), ветка `main`, папка корень. Изменения, загруженные в `main`, появляются на сайте через 1–2 минуты.

## Что внутри

- `index.html` — весь сайт в одном файле (HTML + CSS в блоке `<style>` + инлайн-SVG). Никакой сборки и зависимостей.
- `privacy.html` — политика конфиденциальности (на неё ссылается баннер cookie в футере).
- `CLAUDE.md` — память проекта для Claude Code: правила вёрстки, дизайн, факты о магазине. Хранится только локально, в репозиторий не выкладывается.
- `README.md` — этот файл.
- `images/` — папка для фото игрушек и мастерицы. Появится, когда будут готовы фото. Пока сайт работает без них.

## Как посмотреть

Открой `index.html` двойным кликом в браузере.

## Как опубликовать на GitHub Pages

1. Создай репозиторий на github.com и загрузи в него файлы проекта (кроме `CLAUDE.md`).
2. Открой настройки репозитория → раздел Pages.
3. В источнике выбери ветку `main` и папку корень (root), сохрани.
4. Через минуту-две страница будет доступна по ссылке `https://<твой-логин>.github.io/<репозиторий>/`.

Подписи в интерфейсе GitHub иногда меняются — ориентируйся на раздел Pages в настройках репозитория.

## Как подключить свой домен

1. В настройках Pages найди поле Custom domain и впиши свой домен [заполнить].
2. В настройках домена у регистратора добавь записи DNS, которые покажет GitHub.
3. Когда всё заработает, включи пункт Enforce HTTPS.

Домен подключается не сразу: изменения DNS могут обновляться до нескольких часов.

## Как добавить фото позже

1. Положи фото в папку `images/` рядом с `index.html`. Названия лучше латиницей, например `zayats-bezhevyi.jpg`. Сожми фото, чтобы страница быстро открывалась.
2. Открой проект в Claude Code и напиши, например: «Добавь фото `zayats-bezhevyi.jpg` в карточку бежевого зайца, а `master.jpg` в блок о мастерице».
3. Проверь страницу в браузере и загрузи изменения в репозиторий. GitHub Pages обновит сайт сам.

## Как обновить каталог, цены, акции и условия

1. Поменяй данные в разделе «Содержание» файла `CLAUDE.md`: это единственный источник фактов для сайта. Новая игрушка — новая строка в таблице каталога.
2. Открой проект в Claude Code и напиши: «Обнови сайт по данным из `CLAUDE.md`».
3. Проверь страницу и загрузи изменения в репозиторий.

Так цены и наличие на сайте, в постах и в ответах покупателям не расходятся.
